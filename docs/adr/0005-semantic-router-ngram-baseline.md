# ADR-0005: 시맨틱 라우터의 첫 임베딩은 글자 n-gram

- 날짜: 2026-10-13
- 상태: 채택 (임베딩 모델 선발 후 교체)

## 배경
PRD §7.1은 검색용 임베딩을 그대로 써서 의도를 분류하라고 한다. 임베딩 모델은 아직 선발 전이고 API 키도 없다.

## 결정
`server/agents/router.py`는 임베딩 함수를 주입받는다. 기본값은 글자 1~3-gram 벡터 + 코사인 유사도다. 규칙 검사(의미 없는 입력, 욕설, AI 깨기 시도)를 먼저 하고, 유사도가 낮거나 상위 두 의도 차이가 작으면 LLM 라우터로 넘긴다.

## 근거와 측정
- 분류 1회 평균 0.05초 이내(테스트 `test_router.py::test_fast`).
- 한국어 예시 문장 기준 의도 분류 테스트 통과. n-gram은 실제 임베딩보다 유사도가 낮게 나와 기준값을 0.35로 따로 뒀다(PRD 기본 0.8은 실제 임베딩 기준).

## 영향
- 임베딩 모델을 고르면 embed 함수만 바꾸고 기준값을 다시 잰다. 검색과 같은 임베딩을 쓰면 추가 비용이 0이다.
- 라우터 정확도와 LLM으로 넘어간 비율을 평가 지표로 기록한다(PRD §17).
