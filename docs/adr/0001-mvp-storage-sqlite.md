# ADR-0001: MVP 저장소는 SQLite, 저장소 계층으로 분리

- 날짜: 2026-10-13
- 상태: 채택

## 배경
PRD는 배포 시 Postgres + 벡터 확장을 권장한다(§15). 개발 PC에는 Docker와 Postgres가 없다.

## 결정
MVP는 표준 라이브러리 `sqlite3`로 게임 상태·세이브 슬롯·클리어 이력(`server/storage`)과 기억·청크·관계 그래프(`server/rag`)를 저장한다. SQL은 두 모듈 밖으로 나가지 않는다.

## 근거
- 설치 없이 바로 돌아가고, 테스트가 메모리 DB로 빠르다.
- 세이브 슬롯 묶음과 클리어 삭제 검증(조회 0건)은 SQLite로도 그대로 증명할 수 있다.

## 영향
- 배포 단계에서 Postgres로 옮길 때 두 모듈만 바꾸면 된다.
- 동시 접속이 많아지면 SQLite 쓰기 잠금이 병목이 된다. 배포 전 재판단.
