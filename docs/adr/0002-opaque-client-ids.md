# ADR-0002: 클라이언트에는 판마다 다른 불투명 ID를 보낸다

- 날짜: 2026-10-13
- 상태: 채택

## 배경
증거·블러핑 주장·거짓말의 내부 ID는 사건 작성자(사람이나 작가 에이전트)가 정한다. `ev_cleaner_card` 같은 이름은 그 자체로 범인을 암시한다. PlayerView에서 비밀 필드를 빼도 ID로 정답이 샐 수 있다.

## 결정
`server/game/masking.py`가 판마다 소금(salt)을 섞은 해시 ID(`e_xxxxxxxxxx`)로 바꿔 내보내고, 클라이언트가 보낸 ID는 서버에서 내부 ID로 되돌린다. 모르는 ID는 거부한다(위조 차단). 인물·장소 ID는 역할·장소 이름이 이미 공개 정보라 그대로 쓴다. 진술의 출처 ID도 내보내지 않고, 출처 원문은 별도 API가 플레이어 권한 안에서만 돌려준다.

## 근거
- 테스트 `tests/core/test_view_no_secrets.py`가 내부 ID, 비밀, 정확한 수치(평판·충분도)가 뷰 JSON에 없음을 확인한다.

## 영향
- 같은 사건이라도 판마다 증거 ID가 달라서, 클라이언트 캐시나 공략 공유로 정답을 맞힐 수 없다.
