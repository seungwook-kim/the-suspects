# ADR-0004: NPC 답변은 검증을 마친 뒤 글자 찍힘으로 보낸다 (MVP)

- 날짜: 2026-10-13
- 상태: 채택 (Phase 4에서 재검토)

## 배경
NPC 답변은 감정 태그·근거 id가 붙은 구조화 출력이고, 화면에 나가기 전에 게임 마스터 검사를 통과해야 한다(PRD §7.2, §11.9). 토큰 단위로 바로 흘려보내면 검사 전의 문장이 화면에 나갈 수 있다.

## 결정
MVP는 답변 전체를 받아 검증한 뒤, 서버가 6글자 단위 `TEXT_MESSAGE_CONTENT`로 나눠 보내 글자 찍힘 효과를 낸다. 기다리는 동안 화면은 NPC의 "음…" 표정을 보여 준다.

## 근거와 측정
- 한 번 보여 준 문장을 나중에 지우는 일이 없다(PRD §11.9 출력 검사 원칙).
- 대신 첫 글자까지의 시간 = 전체 답변 생성 시간이다. NPC 답변이 1~3문장(출력 토큰 상한 200)이라 차이가 작을 것으로 보지만, 실제 모델로 p50·p95를 측정해 기록한다.

## 영향
- 예산(첫 토큰 1.5초)을 못 맞추면 Phase 4에서 "문장 단위 스트리밍 + 문장별 검사"로 바꾼다.
