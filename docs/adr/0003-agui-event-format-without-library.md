# ADR-0003: AG-UI 이벤트 형식을 직접 내보낸다 (라이브러리는 나중에)

- 날짜: 2026-10-13
- 상태: 채택

## 배경
PRD §11.10은 화면과 서버 사이 이벤트를 AG-UI 프로토콜로 정했다. `ag-ui-langgraph`는 0.0.47(0.0.x)이라 동작이 자주 바뀐다(0.0.47에서도 오류 이벤트 방식이 바뀜).

## 결정
`server/game/events.py`가 AG-UI 이벤트 이름과 모양(`TEXT_MESSAGE_*`, `STATE_SNAPSHOT`, `STATE_DELTA`(JSON Patch), `CUSTOM`, `RUN_*`)을 그대로 만들어 SSE로 보낸다. 게임 전용 이벤트는 `CUSTOM`의 `name`으로 구분한다(docs/api-contract.md).

## 근거
- 프론트엔드는 표준 이벤트 형식에만 의존하므로, 나중에 라이브러리로 바꿔도 화면 코드는 그대로다.
- 0.0.x 의존성의 위험(PRD 구현 가능성 평가 지표 5)을 피한다.

## 영향
- 라이브러리로 바꿀 때는 스모크 테스트 3종(엔드포인트, 이벤트 순서, 상태 변화분)을 먼저 통과시킨다.
