# 화풍 기준 (PRD §9.1)

## 원칙
- **현대식 깔끔한 플랫 일러스트.** 실사 얼굴 없음. 그라데이션은 최소, 단색 면 + 얇은 외곽선.
- 캐릭터(코드가 SVG로 그림)와 배경(AI 생성)이 같은 화풍이어야 한다.
- 특정 작가·게임 스타일 모방 금지("역전재판 스타일" 같은 요청 금지).
- 범인 여부를 그림에 드러내지 않는다(수상한 표정, 어두운 색 몰아주기 금지).

## 색
| 용도 | 값 |
|:--|:--|
| 배경 기본 (밝은 테마) | `#F4F1EA` |
| 배경 기본 (어두운 테마) | `#1C1E24` |
| 강조 (모순, 경고) | `#E4572E` |
| 증거 카드 | `#FFFFFF` 바탕, `#2E3440` 글자 |
| 외곽선 | `#2E3440`, 1.5~2px |
| 피부 톤 | 시드에서 연속값으로 선택 (밝은 톤 ~ 어두운 톤 고르게) |

## 캐릭터 (절차적 SVG)
- 상반신 초상화, 정면에서 약간 비스듬히. 기본 크기 240×300.
- 시드에서 연속값으로 뽑는 것: 얼굴 폭, 턱선, 눈 크기·간격·눈꼬리 각도, 코 길이, 입 폭, 눈썹 굵기·각도, 머리 모양 곡선, 피부·머리·눈 색.
- 옷은 현대 옷장: `suit`, `casual`, `hoodie`, `cleaner_uniform`, `security_uniform`, `chef`, `doctor`, `delivery`, `school_uniform`, `work_clothes`, `office_lanyard`(사원증). 색과 디테일은 시드로.
- 소품 예: `mop`, `radio`, `laptop`, `badge`, `apron`, `glasses`, `cap`.
- 표정(emotion → 파라미터): neutral(기본), nervous(눈썹 올라감, 입 작게), flustered(눈 커짐, 입 일그러짐 + 💦), angry(눈썹 내려감, 입 꽉 + 💢, 붉은 색조), sad(눈꼬리 내려감), happy(눈 반달, 입꼬리 올라감).
- 대사 중 입 여닫기, 3~6초마다 눈 깜빡임.

## 배경 (AI 생성, Phase 2)
- 생성 요청 공통 문구: "flat vector illustration, clean modern Korean interior, muted palette, soft daylight, no people, no text"
- 사건마다 시간대·날씨·소품을 넣고 시드는 랜덤. 상황 변화는 오버레이(밤: 어둡게, 비: 빗방울, 사건 현장: 폴리스라인, 긴박: 붉은 색조, 정전: 어둡고 깜빡임).
- 그림이 늦으면 임시 배경: 장소 이름 + 아이콘 + 단색 바탕.
