# 화풍 기준 (PRD §9.1)

## 원칙
- **인물: 실사 사진 느낌의 AI 초상화** (2026-10-13 사용자 결정, PRD 부록 D-54). 현대 한국, 평범한 가상의 인물(실존 인물·유명인 닮음 금지),
  자연광, 무표정, 상반신 3:4, 흐린 단색 배경. 판마다 새로 그린다. 요청 문구는 `server/game/portraits.py`.
- 그림 모델: Cloudflare Workers AI `flux-2-klein-4b`(무료 할당량, PRD 부록 D-56). 480×640으로 그려 WebP(품질 80, 장당 약 15KB)로 저장.
  판 그림은 클리어하면 삭제하고, 그린 사진은 사진 보관함(`var/portrait_library/<직업군>/<성별>_<나이대>/`)에 남긴다
  (사건과 잇는 정보 없이 외모 정보·요청 문구·시드만). 직업군 표는 `server/game/portrait_library.py`.
- 옷·소품은 글자 없는 민무늬로 묘사한다(이름표·패치·사원증에 엉터리 글자가 찍히는 것 방지).
- 감정은 같은 얼굴로 그린 표정 사진(긴장·당황·분노·슬픔·기쁨)으로 보여 준다. 그 감정이 처음 나올 때 그리며, 그리는 동안은
  기본 사진 + 화면 효과(흔들림·색조·💦💢). 대사 중에는 미세하게 들썩인다.
- 사진은 가슴 위까지만(바지·신발·손이 보이지 않게). 옷 설명에 하의가 있으면 전신으로 그려지는 문제가 있었다.
- 그림이 없거나(키 없음) 늦거나 로드에 실패하면 **절차적 SVG**로 대신 그린다. 대체 그림도 사람 비율·명암이 있는 반실사풍으로 그린다.
- 배경(AI 생성)은 인물 사진과 어울리는 실사풍 실내 사진으로 맞춘다(Phase 2).
- 특정 작가·게임 스타일 모방 금지("역전재판 스타일" 같은 요청 금지).
- 범인 여부를 그림에 드러내지 않는다(수상한 표정, 어두운 색 몰아주기 금지).

## 캐릭터 대체 그림 (절차적 SVG)
- 상반신 초상화, 정면에서 약간 비스듬히. 기본 크기 240×300. 사람 비율(눈은 머리 세로 중앙, 눈 폭은 얼굴 폭의 1/5), 부드러운 명암, 얇은 외곽선.
- 시드에서 연속값으로 뽑는 것: 얼굴 폭, 턱선, 눈 크기·간격·눈꼬리 각도, 코 길이, 입 폭, 눈썹 굵기·각도, 머리 모양 곡선, 피부·머리·눈 색.
- 옷은 현대 옷장: `suit`, `casual`, `hoodie`, `cleaner_uniform`, `security_uniform`, `chef`, `doctor`, `delivery`, `school_uniform`, `work_clothes`, `office_lanyard`(사원증). 색과 디테일은 시드로.
- 소품 예: `mop`, `radio`, `laptop`, `badge`, `apron`, `glasses`, `cap`.
- 표정(emotion → 파라미터): neutral(기본), nervous(눈썹 올라감, 입 작게), flustered(눈 커짐, 입 일그러짐 + 💦), angry(눈썹 내려감, 입 꽉 + 💢, 붉은 색조), sad(눈꼬리 내려감), happy(눈 반달, 입꼬리 올라감).
- 대사 중 입 여닫기, 3~6초마다 눈 깜빡임.

## 배경 (AI 생성, Phase 2)
- 생성 요청 공통 문구: "photorealistic photo, clean modern Korean interior, muted palette, soft daylight, no people, no text"
- 사건마다 시간대·날씨·소품을 넣고 시드는 랜덤. 상황 변화는 오버레이(밤: 어둡게, 비: 빗방울, 사건 현장: 폴리스라인, 긴박: 붉은 색조, 정전: 어둡고 깜빡임).
- 그림이 늦으면 임시 배경: 장소 이름 + 아이콘 + 단색 바탕.
