# 테스트·측정 기록

PRD에는 설계와 결정만 적고, 테스트와 측정의 방법·수치·한계는 여기에 따로 남긴다(PRD §17.5).

- 파일 이름: `날짜-주제.md` (예: `2026-10-14-response-latency.md`)
- 한 파일에 담는 것: 목적, 환경, 방법(다시 돌리는 법), 결과 표, 해석, 한계, 다음 할 일
- 개선 작업을 했으면 같은 측정을 다시 돌려 전후 수치를 나란히 적는다.
- 저장소에 올리지 않는 실행 기록(`var/traces.jsonl` 등)을 근거로 쓸 때는 어느 판·시각의 기록인지 적는다.
